# Journey image enhancement

Tool: built-in image_gen, editing the existing 2024, 2025 and 2026 JPGs.

Prompt used for each image:

Enhance this exact low-resolution cinematic photograph for a portfolio timeline card. Restore crisp realistic edges and fine texture, remove pixelation and compression blur, high resolution. Preserve the exact subject, framing, warm colors, lighting, objects and composition. Do not add text, objects or borders. Output only the enhanced photograph, landscape, at least 1024 pixels wide.

Saved assets: public/years/2024-clear.png, public/years/2025-clear.png, public/years/2026-clear.png. Original JPGs are preserved. The enhancement reconstructs detail rather than recovering original photographic information.

Project cards retain their existing assets with light rendering sharpening and brightness correction. Gallery grain is reduced to 30 percent.
